# ❌⭕ Tic Tac Toe Web App

![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)

A clean, responsive, and interactive Tic Tac Toe web application built with vanilla HTML, CSS, and JavaScript. Play against a friend locally in pass-and-play mode or challenge a rule-based AI opponent!

---

## ✨ Features

- **Dual Game Modes:** Choose seamlessly between 2-Player (Pass & Play) or Player vs Computer (AI).
- **Smart AI Opponent:** Employs a tactical heuristic strategy that prioritizes winning moves, blocks opponent wins, claims the center, and secures corners.
- **Scoreboard Tracking:** Automatically tracks and displays wins for Player X, Player O / AI, and ties across multiple rounds (persisted via `localStorage`).
- **Round & Session Management:** Easily jump to the next round while keeping scores intact, or reset the entire session.
- **Polish & Effects:** Features animated win lines, Web Audio API sound effects, canvas confetti explosions, and modal popup banners!
- **Modern UI & Responsive Design:** Styled with a clean, modern aesthetic that works smoothly on both desktop and mobile screens.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic layout and structural elements.
- **CSS3:** Custom CSS Grid styling, hover states, win animations, and responsive layout.
- **JavaScript (ES6):** Game state management, event handling, win condition checking, Web Audio API, and AI decision logic.
